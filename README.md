# WorkWise AI

Small, production-style AI automation workflow examples: structured outputs, schema validation,
retries, mock providers, and explicit failure handling. Everything runs locally against
deterministic mocks by default — no API key required.

Full architecture notes, workflow diagrams, and setup/testing instructions are on the way in
[README.md](README.md) as the workflows land. See the commit history for progress.
